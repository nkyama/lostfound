# webサイト制作
忘れ物共有サイト

## 概要
HTML、CSS、JavaScriptを使ってWebサイトを作成するプロジェクトです。

## 使用技術
- HTML
- CSS
- JavaScript

## 実行方法
1. レポジトリをダウンロードする
2. SupabaseのSQL Editorで `supabase-profiles.sql` を実行する
3. `index.html` をブラウザで開く

新規登録時に表示名を設定できます。ログイン後は `mail.html` で表示名を変更できます。

## メンバー
- 自分のGitHubユーザー名
- 共同開発メンバーのユーザー名
